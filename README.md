# YHQ Imtihon — тренажёр ПДД РУз (Telegram Mini App)

Тренажёр для подготовки к экзамену по ПДД Республики Узбекистан. **Не официальные экзаменационные билеты.**

- Mini App: https://t.me/YHQbilet_bot/test
- Хостинг: GitHub Pages (`main` публикуется автоматически)
- `index.html` — приложение, `questions.js` — база вопросов (RU/UZ)

## Правила для базы вопросов
Новые вопросы добавлять **только в конец** `questions.js`. Номер вопроса = порядковый номер, по нему хранится прогресс пользователей.

## Статистика
Приложение отправляет анонимные события (хеш Telegram ID, без имён) на Cloudflare Worker `pdd-stats`.
Сводка — в боте Timur AI: `/stats`, `/yesterday`, `/week`, `/month`, `/all`; ежедневно в 9:00 (Ташкент).
